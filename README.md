# python斩 · 管理后台演示

一个纯前端单文件演示页，用**虚构数据**展示：当所有账号、学习进度、设备和会话汇聚到运营者手里时，管理后台是什么样子。

> 页面里的账号、学校、IP、密码哈希、Token 全部是编造的；页面不联网、不写数据库、没有任何真实用户数据。

## 在线预览

<https://sycamore327.github.io/admin-console-demo/>

演示账号：`admin` / `demo1234`（本地演示，随便填也能进）。登录后点任意一行账号查看详情。

## 这个演示想说明什么

- 后台入口不是“隐藏网址”，而是独立的管理员登录 + 权限校验
- 管理员能看到的不只是账号：学校、IP 归属地、设备、学习行为、会话、合并记录
- Bcrypt 哈希不能还原明文密码，但管理员可以重置密码、强制下线、导出数据、删除账号
- 因此自建账号系统的真正成本，是长期的运维、隐私合规和事故责任

页面底部列出了“你能看到 / 仍然看不到 / 但实际能做到 / 因此要承担”四块内容。

## 技术说明

- 单文件 `index.html`，内联 CSS / JavaScript，无依赖、无后端
- 数据全部写死在页面里
- 已适配手机屏幕
